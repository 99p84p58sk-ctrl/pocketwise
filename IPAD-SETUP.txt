POCKETWISE — iPad setup

IMPORTANT: iPad Home Screen web apps need an HTTPS website address. This ZIP contains the complete app files, but it is not an App Store app and cannot install itself directly.

EASIEST ROUTE (GitHub Pages, free):
1. On your iPad or a computer, sign in to GitHub and create a new public repository named pocketwise.
2. Upload ALL files from this ZIP (index.html, manifest.webmanifest, service-worker.js, icon-192.png, icon-512.png) to the repository's main/root folder.
3. In the repository, open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish the site. It will show a URL similar to https://YOUR-USERNAME.github.io/pocketwise/
6. Open that URL in Safari on your iPad.
7. Tap Share (square with upward arrow) → Add to Home Screen → Add.
8. Open PocketWise from the new Home Screen icon.

FEATURES:
- Set monthly pocket-money budget.
- Add expenses with amount, category, description and date.
- Automatically calculates this month's total spent and remaining balance.
- Daily spending lookup.
- Transaction history with delete.
- Export transaction history as CSV.
- Dark theme and iPad-friendly responsive layout.
- Saves data in that Safari web app's local storage on the iPad.

DATA NOTE:
Your entries are stored locally in Safari on that iPad. They do not sync automatically to other devices. Avoid clearing Safari website data unless you have exported a CSV backup. Export CSV regularly from History.

To update the app later, upload the replacement files to the same GitHub repository. Refresh the site in Safari.
